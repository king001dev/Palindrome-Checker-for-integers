#  Palindrome Checker

A simple **Java** console program that checks whether an integer is a **palindrome** — a number that reads the same forwards and backwards (e.g., `121`, `1221`, `7`).

---

##  Features

-  **Integer input** — reads a number from the console
-  **Palindrome check** — reverses the digits and compares with the original
-  **Input validation** — keeps asking until a valid integer is entered
-  **Negative numbers** — automatically treated as **not palindromes**

---
